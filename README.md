## 🚀 Project Overview

This project is a custom-built drone developed with a focus on **carrying additional payloads**.

The project involved CAD design, mechanical development, component selection, electronics integration, assembly, radio-control setup and repeated flight practice.

The main goal was to develop and test a drone configuration capable of carrying an additional payload while maintaining stable and controllable flight.

# 📡 Radio Control System

The drone uses an **ExpressLRS (ELRS)** radio-control system.

### Transmitter

**RadioMaster T8L ELRS**

Used by the pilot to control the drone during flight and practice sessions.

![RadioMaster T8L ELRS](Components/radiomaster-t8l-elrs.jpg)

### Receiver

**RadioMaster RP2 ELRS**

Installed on the drone to receive control commands from the transmitter.

![RadioMaster RP2 ELRS](Components/radiomaster-rp2-elrs.jpg)

### Control Link

```text
        RadioMaster T8L ELRS
                 │
                 │
           ExpressLRS
                 │
                 ▼
        RadioMaster RP2 ELRS
                 │
                 ▼
          Flight Controller
                 │
                 ▼
              ESCs
                 │
                 ▼
              Motors
                 │
                 ▼
            Propellers
```

This radio-control system was used during our flight practice and testing.
